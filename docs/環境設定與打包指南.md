## 環境設定

### 基本需求

運行或開發此應用程式需要以下基本要求：

- **Python 3.8 或更高版本**（建議使用 Python 3.10+）
- **FFmpeg**（開發時必要，使用打包版本時已內建）
- **Git**（用於源碼管理，可選）

### Python 虛擬環境

建議使用虛擬環境來開發和測試應用程式，以避免依賴衝突。

#### Windows

```batch
# 創建虛擬環境
python -m venv .venv

# 激活虛擬環境
.venv\Scripts\activate
```

#### macOS / Linux

```bash
# 創建虛擬環境
python3 -m venv .venv

# 激活虛擬環境
source .venv/bin/activate
```

### 安裝依賴

#### 一般使用依賴

```bash
pip install -r requirements.txt
```

#### 開發專用依賴（包括測試和打包工具）

```bash
pip install -r requirements-dev.txt
```

### FFmpeg 安裝

FFmpeg 是必須的媒體處理工具。**注意：** 如果您使用的是打包版本的應用程式，FFmpeg 已經內建，您無需另外安裝。

以下是在開發環境下安裝 FFmpeg 的方法：

#### Windows

1. 從 [FFmpeg 官方網站](https://ffmpeg.org/download.html) 下載預編譯的二進位檔案
2. 解壓縮到指定目錄，例如 `C:\ffmpeg`
3. 將 FFmpeg 的 bin 目錄添加到系統 PATH 環境變數：
   - 打開「控制台」->「系統和安全性」->「系統」->「進階系統設定」
   - 點擊「環境變數」
   - 在「系統變數」下找到 Path 並編輯
   - 添加 `C:\ffmpeg\bin`
   - 確認並關閉所有視窗
4. 重新啟動命令提示符或 PowerShell
5. 驗證安裝：`ffmpeg -version`

#### macOS

使用 Homebrew 安裝：

```bash
brew install ffmpeg
```

驗證安裝：`ffmpeg -version`

#### Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install ffmpeg
```

驗證安裝：`ffmpeg -version`

## 打包應用程式

### 使用打包腳本

專案提供了自動化打包腳本，位於 `scripts` 目錄下。**這些腳本會自動下載並包含最新版的 FFmpeg，因此終端用戶無需另外安裝 FFmpeg。**

#### Windows

直接運行 `scripts\build_windows.bat` 批處理檔案：

```batch
cd 專案根目錄
scripts\build_windows.bat
```

腳本會自動完成以下操作：
1. 創建並激活虛擬環境
2. 安裝必要依賴
3. 下載並配置最新版 FFmpeg
4. 使用 PyInstaller 打包應用程式
5. 創建必要的目錄結構
6. 生成 ZIP 檔案

#### macOS / Linux

先確保腳本具有執行權限：

```bash
chmod +x scripts/build_unix.sh
```

然後運行腳本：

```bash
cd 專案根目錄
./scripts/build_unix.sh
```

腳本會自動完成類似 Windows 版本的打包操作，但會根據作業系統（macOS 或 Linux）進行相應調整，並自動下載對應平台的 FFmpeg。

### 手動打包

如果打包腳本不適用於您的環境，或者您需要自定義打包過程，可以手動執行 PyInstaller，但需要自行處理 FFmpeg：

```bash
# 安裝 PyInstaller
pip install pyinstaller

# 基本打包命令
pyinstaller --onefile --windowed --name="YouTube下載工具" src/main.py

# 高級打包命令 (Windows，需要自行下載 FFmpeg)
pyinstaller --onefile --windowed --icon=assets/icon.ico --name="YouTube下載工具" --add-data "src;src" --add-data "path\to\ffmpeg;ffmpeg" src/main.py

# 高級打包命令 (macOS/Linux，需要自行下載 FFmpeg)
pyinstaller --onefile --windowed --icon=assets/icon.png --name="YouTube下載工具" --add-data "src:src" --add-data "path/to/ffmpeg:ffmpeg" src/main.py
```

### 打包注意事項

1. **FFmpeg 整合**：打包腳本會自動下載並整合 FFmpeg，終端用戶無需另外安裝
2. **目錄結構**：打包後的應用程式會自動創建以下目錄：
   - `downloads/audio`
   - `downloads/video`
   - `downloads/thumbnails`
3. **資源文件**：打包腳本會自動包含必要的資源文件，如圖標和 README
4. **系統差異**：在不同的作業系統上，某些功能可能會有差異，特別是文件路徑處理

## 疑難排解

### 打包過程中的常見問題

1. **FFmpeg 下載失敗**
   - 檢查網絡連接
   - 可以嘗試手動下載 FFmpeg 並放置在 `ffmpeg` 目錄中
   - Windows 上確保 `ffmpeg/ffmpeg.exe` 存在
   - macOS/Linux 上確保 `ffmpeg/ffmpeg` 存在並有執行權限

2. **找不到模組**
   - 檢查 requirements.txt 是否包含所有依賴
   - 嘗試使用 `--hidden-import` 指定缺失的模組

3. **資源文件不存在**
   - 確保所有資源文件都在正確的位置
   - 檢查 `--add-data` 參數是否正確

4. **打包後的應用程式無法運行**
   - 檢查日誌（通常在用戶臨時目錄中）
   - 確保打包時包含了 FFmpeg
   - 檢查文件權限

### 運行時的常見問題

1. **內建 FFmpeg 無法運行**
   - 程式會嘗試使用系統上已安裝的 FFmpeg
   - 如遇問題，可檢查打包的應用程式中是否包含 `ffmpeg` 目錄
   - 確保 ffmpeg 執行檔沒有被防毒軟件攔截

2. **資料庫錯誤**
   - 檢查資料庫檔案是否存在且未損壞
   - 考慮刪除資料庫檔案讓應用程式重新創建（會失去下載歷史）

3. **UI 顯示問題**
   - 確保 PyQt6 正確安裝
   - 在不同的桌面環境中可能有不同顯示效果
